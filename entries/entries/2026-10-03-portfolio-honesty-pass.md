# Portfolio Live + The Honesty Pass

Shipped my portfolio today: https://chalidade.github.io

Then ran an "honesty pass" over everything public — portfolio, CV, LinkedIn:

- Replaced every claim I couldn't defend with one I can: "70% solo" became
  "490+ merged PRs, 80%+ of all frontend PRs since April 2026" — verified
  against git history, not memory
- Removed "Next.js 16" from my stack until something I own actually runs on 16
- Changed "AI-powered recommendations" to "currently adding" — the feature
  isn't built yet, so the words say so
- Fixed a dead domain link before a recruiter could click it

**Lesson:** a sharp interviewer only needs to catch one soft claim to doubt
all the hard ones. Defensible beats impressive, every time.
